# 🖥️ Local Development

Clone the repository

```bash
git clone https://github.com/Khushboo1976/khushboo-portfolio.git
```

Move inside the project

```bash
cd khushboo-portfolio
```

Install dependencies

```bash
npm install
```

Run development server

```bash
npm run dev
```

Open

```
http://localhost:3000
```

Build production

```bash
npm run build
```
